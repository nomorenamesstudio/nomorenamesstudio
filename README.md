## Why these exist

Every tool here started as something we needed and could not find: a job hunt that needed a timeline, a wall for a folder of photographs, a jukebox remote. We build for our own itch first. The source goes up in case it scratches yours too.

## FAQ

### Are the tools really free?
Yes. MIT, no paid tier, no upsell. Clone a repo and run it yourself, or use the hosted one where there is one.

### What does it take to run them?
Node or Docker for ghosted and juuku. keret turns a folder of photographs into a static wall you can put on GitHub Pages for nothing.

### Why no AI in the tools?
Because you should not need an API key and a credit card to track a job application, or to control your speakers. The studio builds with AI in the loop — the tools run without it, no tokens, no model bill to pass on.

### Do you take contract work?
Yes: coding, design, user experience, accessibility. Write to hey@nomorenames.studio with what you are building and when it has to land.
